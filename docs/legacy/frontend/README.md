# Archived prototype UI

These screens, service adapters, and placeholder tests belonged to the earlier microservice prototype. They were not mounted in the deployed review product and are retained here for reference. Their React 18 dependency manifest is historical; the active frontend lives in `src/frontend` and builds with Next.js and React 19.

The active frontend includes the real review-flow tests. The three archived test files only asserted `true`; they are not included in current coverage or test counts.
